### Corrections

- `put()` attend la fin de l’upload : ses erreurs sont propagées (et mappées) au lieu de devenir des rejets non gérés, et `raw` contient le résultat de l’upload au lieu d’une promesse.
- `put()` écrit une chaîne comme contenu du fichier, conformément au contrat `AbstractStorage` ; ssh2-sftp-client ne l’interprète plus comme le chemin d’un fichier local à téléverser.
- `getStream()` renvoie un flux lisible alimenté par `createReadStream()` ; un fichier absent fait émettre une `FileNotFoundException` sur ce flux, et le flux distant est libéré si le consommateur abandonne la lecture.
- `get()` ne préfixe plus deux fois la racine du disque.
- Les erreurs SFTP sont mappées sur les exceptions Factorydrive : statut 2 / `ENOENT` → `FileNotFoundException`, statut 3 / `EACCES` → `PermissionMissingException`, les autres → `UnknownException` avec le code d’origine. Les noms d’erreur S3 ne sont plus interprétés.

### Documentation

- Le README déclare le disque via `FactorydriveModule.forRoot()` et utilise `getDisk()` : `createDisk()` et `disk()` n’existent pas sur `FactorydriveService`.
